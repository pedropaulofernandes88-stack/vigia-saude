# Origem da proposta

O conceito foi inspirado na análise do projeto público **Painel COVID-19 — 15ª Regional de Saúde do Paraná**, de marco-leal-analytics, desenvolvido no contexto da UEM e da regional de saúde:

https://github.com/marco-leal-analytics/painel-covid19-15-regional-saude-pr

Na consulta de 10/09/2026, a API do GitHub não identificou licença no repositório de referência. Por isso, esta é uma implementação própria em Python e JavaScript, sem incorporação de seu código, dados de pacientes, logotipos ou ativos. A referência conceitual é a separação entre ingestão, tratamento, indicadores e aplicação.

Não há vínculo institucional presumido com a UEM, a 15ª Regional ou o Ministério da Saúde. As fontes públicas utilizadas são identificadas nos manifestos de cada execução. Seus termos próprios permanecem aplicáveis aos dados.
